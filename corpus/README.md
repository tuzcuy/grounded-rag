# Default corpus

Five IETF RFCs, reproduced unmodified from [rfc-editor.org](https://www.rfc-editor.org/):

| File | Title |
|---|---|
| rfc2119.txt | Key words for use in RFCs to Indicate Requirement Levels |
| rfc6265.txt | HTTP State Management Mechanism (cookies) |
| rfc6749.txt | The OAuth 2.0 Authorization Framework |
| rfc7519.txt | JSON Web Token (JWT) |
| rfc9112.txt | HTTP/1.1 (message syntax) |

RFCs are freely redistributable in unmodified form — RFC 2119 states
"Distribution of this memo is unlimited", and later documents are covered by
the [IETF Trust Legal Provisions](https://trustee.ietf.org/documents/trust-legal-provisions/),
which grant the right to reproduce and distribute RFCs.

Drop your own `.md`, `.txt` or `.pdf` files in here (or point the indexer at
any directory) and rebuild the index.
